# Hermes Kanban demo video — creative/message brief

Recommended duration: 15 seconds (works as a tweet/social clip; understandable muted)

Core message:
Hermes Kanban turns multi-agent work from an invisible chat into a visible production board: one goal becomes parallel agent tasks, dependencies show how work fans out and back in, and every card's status is obvious.

Key beats:
1. 0–3s — Parent goal lands
   - Visual: One large parent card appears: “Make Hermes Kanban demo video.”
   - On-screen title: “Agent orchestration, visible.”
   - Caption: “Start with one goal.”

2. 3–7s — Director decomposes into parallel children
   - Visual: Dependency lines fan out from the parent into researcher, designer, animator, editor, reviewer cards.
   - Labels: “Director”, “Research”, “Storyboard”, “Animate”, “Edit”, “Review”
   - Caption: “Hermes breaks it into parallel work.”

3. 7–12s — Cards move through workflow states
   - Visual: Cards slide across columns: todo → ready → running → blocked/done. One card briefly hits blocked, then resumes; others complete in parallel.
   - Column labels: “todo”, “ready”, “running”, “blocked”, “done”
   - Caption: “Every agent has state. Every dependency is clear.”

4. 12–15s — Fan-in and final output
   - Visual: Completed child cards fan back into final review/output card; dashboard settles with most cards in done.
   - Caption: “Fan out. Fan in. Ship.”
   - Final CTA/tagline: “Hermes Kanban: watch your agents work.”

Exact copy package:
- Title: “Agent orchestration, visible.”
- Parent card: “Goal: make a demo video”
- Child card labels: “Research”, “Storyboard”, “Animate”, “Edit”, “Review”
- Column labels: “todo”, “ready”, “running”, “blocked”, “done”
- Status captions:
  - “Start with one goal.”
  - “Director splits it into parallel tasks.”
  - “Cards move as agents work.”
  - “Dependencies fan out — then fan in.”
  - “Fan out. Fan in. Ship.”
- Final CTA/tagline: “Hermes Kanban: watch your agents work.”

Wording decisions:
- Use “visible” as the hook because the value prop is seeing agent orchestration rather than reading logs.
- Use “fan out / fan in” because it directly maps to the dependency-line visual.
- Keep labels short and lowercase for status columns so the clip remains legible on mobile.
- Avoid explaining implementation details; focus on board motion, task state, and parallelism.
