# TikTok-style Minimal Viable Product Scope

## Goal

Create a simple, privacy‑friendly short‑video feed and posting mechanic that respects brand and legal constraints.

## Core Features

1. **Video Upload** – User can record or upload a short video (≤ 15s) in common formats (mp4, mov).
2. **Feed** – A chronological list of videos from followed users.
3. **Like / Comment** – Basic engagement metrics (count, add comment).
4. **User Profile** – Basic profile page with avatar, name, and video list.
5. **Privacy** – No target‑ad or location tracking; consent required for any external service.

## Constraints

- No copyrighted or protected content. All videos must be user‑generated or user‑approved.
- No brand copy or directly mimicking proprietary UI elements.
- The MVP focuses on the minimal core to validate the idea; UI can be skeleton.
