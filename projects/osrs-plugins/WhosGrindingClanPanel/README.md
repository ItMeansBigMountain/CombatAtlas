# WhosGrindingClanPanel

[![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-%E2%82%AC%F0%9F%9F%BD?style=for-the-badge)](https://ko-fi.com/affanfareed)

## Overview
A standalone OSRS plugin that shows currently active grinders in your clan. Designed to work with RuneLite's latest client versions.

## Features
- Real-time grinder list
- Skill filters
- Experience gain rates

## Installation
1. Download the latest `.jar` file from the releases section
2. Place the JAR file in your `~/.runelite/plugins/` directory
3. Enable the plugin in the RuneLite plugin menu

## Usage
Open the clan panel to see who's currently grinding which skills.
