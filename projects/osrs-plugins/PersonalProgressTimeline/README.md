# PersonalProgressTimeline

[![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-%E2%82%AC%F0%9F%9F%BD?style=for-the-badge)](https://ko-fi.com/affanfareed)

## Overview
A standalone OSRS plugin that tracks and displays your personal milestone history. Designed to work with RuneLite's latest client versions.

## Features
- Skill milestone timeline
- Achievement unlock dates
- Progress visualization

## Installation
1. Download the latest `.jar` file from the releases section
2. Place the JAR file in your `~/.runelite/plugins/` directory
3. Enable the plugin in the RuneLite plugin menu

## Usage
View your timeline to track personal progress milestones.
