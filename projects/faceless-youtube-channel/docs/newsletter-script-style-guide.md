# Newsletter avatar storytelling + visual variety guide

Last updated: 2026-06-15.

Use this for faceless newsletter videos sourced from `fareed320` and uploaded to Trapiistan/Sosai Oyama.

## Direction

The video should feel like a charismatic avatar/personality is telling viewers the news, not like a school outline or “intro/body/conclusion” essay. The avatar should sound like a sharp host with taste: curious, funny when appropriate, opinionated, and able to turn a dry newsletter into a mini-story.

## Script rules

- Do **not** make the spoken narration feel structured, templated, or sectioned.
- Captions can have punchy labels, but the voiceover should be one continuous monologue.
- Avoid repetitive formulas like “the signal,” “operator angle,” “move first,” or “in conclusion.”
- Use natural transitions only when they sound conversational.
- The hook should feel like a friend saying: “wait, did you see this?”
- The middle should build stakes and curiosity, not summarize bullet points.
- Humor is welcome when it fits the topic, but do not trivialize hacks, layoffs, injuries, or real harm.
- End with a practical takeaway that feels earned, not bolted on.

## Avatar tone examples

Good:

> AI had another weird little plot twist. Somewhere, a roadmap just got rewritten in panic font. The tools are not the whole story anymore — the real story is whether these demos are turning into workflows people can actually ship with.

Bad:

> Introduction: AI is changing. Body: tools are useful. Conclusion: build one proof.

## Visual variety rules

The user wants more variety and less repeated footage.

- Use more scenes per video when the script supports it, normally 8–10 visual segments.
- Derive visual queries from company names, products, category, emotion, and scene mood.
- Avoid using the same generic “people on laptop” footage every time.
- Mix visual types: office, product/app, city, server room, hands on keyboard, dashboards, teams, late-night founder desk, abstract data, relevant company/category images.
- Keep a visual asset history so future renders avoid reusing the same URLs when possible.
- Save `visual_manifest.json` for QA.

## Voice experiments

Parrot AI may be useful for testing familiar/entertainment-style voices, but we need to verify if it has an API or usable export workflow. For public channel safety, prefer original/parody-inspired personas rather than exact impersonation of protected celebrities or characters. A “high-energy nautical cartoon-ish tech host” is safer than “SpongeBob says this news.”
