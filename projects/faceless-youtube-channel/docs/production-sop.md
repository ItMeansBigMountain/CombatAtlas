# Production SOP

## Per-Video Folder

Create each video under:

`videos/YYYY-MM-DD-short-title/`

Recommended files:

- `brief.md`
- `research.md`
- `script.md`
- `visual-plan.md`
- `thumbnail.md`
- `metadata.md`
- `postmortem.md`

## Workflow

### 1. Brief

Define:

- Target viewer.
- Pain/desire.
- Big promise.
- Core lesson.
- Emotional angle.
- Main source links.

### 2. Research

Gather:

- 5–10 source links.
- Competing videos.
- Key stats/facts.
- Contrarian angle.
- Personal connection if applicable.

### 3. Script

Structure:

1. Hook: 0:00–0:15.
2. Stakes: 0:15–0:45.
3. Context: 0:45–2:00.
4. Main breakdown: 2:00–6:30.
5. Payoff/lesson: 6:30–8:30.
6. CTA: final 10 seconds.

### 4. Visual Plan

For every 10–20 seconds:

- On-screen text.
- B-roll/search terms.
- AI image/video prompts.
- Screenshot/graph idea.
- Motion notes.

### 5. Thumbnail + Title

Create at least 5 packages before choosing one.

### 6. Upload

Prepare:

- Final title.
- Description.
- Chapters.
- Tags/hashtags.
- Pinned comment.
- Shorts cutdowns.

### 7. Postmortem

After 48–72 hours:

- CTR.
- Average view duration.
- Retention drop-offs.
- Comments/themes.
- Next experiment.
